# 模板选用指南

`templates/` 里是一批**开箱即用的 `gen.py` 模板**：每做一道题，挑一个最像的，
改两三行（标着 `← 改这里` 的地方）就能拿去跑压力测试。

配套的 `templates/examples/` 里，每个模板都配了一个 5~15 行的最小目标程序，
用来验证"这个模板生成的输入是合法的、能被吃掉"。

---

## 1. 怎么用

```bat
python main.py 你的程序.py --gen templates/gen_array.py --seed 123
```

* `--gen` 指定用哪个模板当数据生成规则（不指定就找 `main.py` 同目录的 `gen.py`）；
* `--seed 123` 固定随机种子，同一颗种子每次生成的数据完全一样，方便复现。

**先验一遍模板自己是好的**（应该看到 `通过 200 组 / 崩 0 组 / 超时 0 组`）：

```bat
python main.py templates/examples/gen_array_target.py --gen templates/gen_array.py --count 200 --seed 123
```

**在图形界面（app.py）里用模板**：把模板文件的内容整段复制到界面左边的 `gen.py` 编辑区，
点「保存 gen.py」即可（界面固定用 `main.py` 旁边那份 `gen.py`）。

## 2. 选哪个模板

| 题目长什么样 | 用哪个模板 | 大概要改哪几行 |
| --- | --- | --- |
| 第一行 `n`，第二行 `n` 个整数；求和 / 排序 / 最值 / 前缀和 / 双指针 | `gen_array.py` | `N_MAX`、`VALUE_MIN/MAX`，需要别的类型就改 `make_value()` |
| 输入就一行字符串；统计字符 / 回文 / 大小写 / 子串 | `gen_string.py` | `LEN_MAX`，想限制字符种类就改 `POOL_*` 和 `make_char()` |
| "不知道有多少组"，一直读到 EOF | `gen_multi.py` | `T_MAX`、`N_MAX`、`VALUE_MIN/MAX` |
| 第一行 `n m`，接下来 `n` 行每行 `m` 个数；矩阵 / 网格 | `gen_matrix.py` | `N_MAX`、`M_MAX`、`VALUE_MIN/MAX` |
| 第一行 `n m`，接下来 `m` 行是边；最短路 / 并查集 / 生成树 | `gen_graph.py` | 无权图 `HAS_WEIGHT=False`；点从 0 开始 `BASE=0`；`N_MAX`、`M_MAX` |
| 先给一个数组，再给 `q` 次区间询问 | `gen_query.py` | `N_MAX`、`Q_MAX`、`VALUE_MIN/MAX`；改询问形式就动 `make_query()` |
| 都不太像 | 复制最接近的那个 | 改 `gen()` 里拼字符串的那几行，其余（随机源、雷、规模常量）照抄 |

## 3. 每个模板一行示例命令

```bat
python main.py my_prog.py --gen templates/gen_array.py  --seed 123
python main.py my_prog.py --gen templates/gen_string.py --seed 123
python main.py my_prog.py --gen templates/gen_multi.py  --seed 123
python main.py my_prog.py --gen templates/gen_matrix.py --seed 123
python main.py my_prog.py --gen templates/gen_graph.py  --seed 123
python main.py my_prog.py --gen templates/gen_query.py  --seed 123
```

## 4. 默认就混进去的"雷"

每个模板**默认**都会生成这些歪数据（不是可选项，是刻意留的）：

| 模板 | 默认混进的雷 |
| --- | --- |
| `gen_array.py` | 空输入；`n=1`；`n=N_MAX`；每组的第一个元素是 `0`、最后一个是负数、第二个是 `VALUE_MAX` |
| `gen_string.py` | 空串（只有换行）；整行都是空格；只有一个字符；长度顶到 `LEN_MAX`；保证出现 `'0'` 和 `'-'`；随机给首尾加空格 |
| `gen_multi.py` | 一组都没有；只有一组且只有 1 个元素；`T_MAX` 组 × `N_MAX` 个元素；**某一组 `k=0`**（专治读 `k` 再读 `k` 个数的死循环）；每组都有 0/负数/上界 |
| `gen_matrix.py` | 空输入；`0 0` 空矩阵；`1 1`；退化成 1 行；退化成 1 列；`N_MAX × M_MAX`；每行都有 0/负数/上界 |
| `gen_graph.py` | 空输入；`n=1, m=0` 孤点；`m=0`（全是孤立点）；`N_MAX` 点 `M_MAX` 边；边权里有 0/负数/上界；30% 概率给链或星形；默认**去重、无自环**，要喂自环/重边就打开 `ALLOW_SELF_LOOP` / `ALLOW_DUPLICATE` |
| `gen_query.py` | 空输入；`n=q=1`；`N_MAX` 数组 `Q_MAX` 询问；数组里有 0/负数/上界；询问里保证出现 `l == r` 和 `l=1, r=n`；要喂 `l > r` 的非法区间就打开 `ALLOW_REVERSED_QUERY` |

模板里写着「不要删」的注释就是这些雷，**别删**——它们才是压力测试真正能抓到 bug 的地方。
真想让数据干净一点，就把那几行注释掉，或者把对应的概率常量调成 `0`。

## 5. 数据规模：怎么调大做压力测试

每个模板顶部都有一行规模常量，默认值很小（方便肉眼检查），跑压力测试时调大：

| 模板 | 规模常量（默认） | 压力测试建议 |
| --- | --- | --- |
| `gen_array.py` | `N_MAX = 10` | `N_MAX = 200000` |
| `gen_string.py` | `LEN_MAX = 12` | `LEN_MAX = 200000` |
| `gen_multi.py` | `T_MAX = 4`、`N_MAX = 8` | `T_MAX = 100000`、`N_MAX = 100` |
| `gen_matrix.py` | `N_MAX = 4`、`M_MAX = 5` | `N_MAX = 1000`、`M_MAX = 1000` |
| `gen_graph.py` | `N_MAX = 6`、`M_MAX = 8` | 稀疏图 `N_MAX = M_MAX = 200000` |
| `gen_query.py` | `N_MAX = 8`、`Q_MAX = 5` | `N_MAX = Q_MAX = 100000` |

调大规模以后记得把超时也放宽，否则全变成「超时」：

```bat
python main.py my_prog.py --gen templates/gen_query.py --count 50 --timeout 3
```


## 7. 几条硬规矩（想自己改模板时注意）

1. **随机数只能用 `rnd` 或已播种的全局 `random`。**
   `main.py` 会注入 `rnd = random.Random(SEED)`，并对全局 `random` 播种。
   绝对不要用 `os.urandom()`、`time.time()`、`random.Random()`，否则 `--seed` 就白给了。
2. **`gen()` 返回一个字符串**，就是这一组完整的输入，建议末尾带换行。
3. **生成的数据要自洽**：声明 `n` 个就真给 `n` 个，图里点编号不能越界。
   边界值是故意给的，但"说 5 个只给 3 个"不是边界，是 bug。
4. **规模用顶部常量控制**，不要写死在 `gen()` 里。

## 8. 常见问题

**Q：`gen_graph.py` 为什么默认带边权？我想生成无权图。**
A：因为无权图的点编号是 `1..n`，里面根本没有 0 和负数——"0 和负数"这两个雷就无处可放，
所以默认把它们放在边权上（`HAS_WEIGHT = True`）。你的题是无权图就把这一行改成 `False`，
同时把 `templates/examples/gen_graph_target.py` 里的 `WIDTH` 改成 `2`。

**Q：模板里的 `rnd` 在我自己直接跑的时候是啥？**
A：单独运行模板（`python templates/gen_array.py`）时，文件末尾的预览代码会临时
`rnd = random` 顶一下。真正跑测试时是 `main.py` 注入的 `random.Random(SEED)`。

**Q：怎么确认模板本身没问题？**
A：跑自检，它会检查"可复现、数据自洽、雷都出现、配套示例能吃掉 200 组"：

```bat
python _selftest\template_check.py
```

**Q：想加一个新模板？**
A：复制最接近的一个，改文件名和 `gen()`，然后在 `templates/examples/` 里照着配一个
最小目标程序，最后把 `_selftest/template_check.py` 里的 `NAMES` 加一项即可。
